# Kc Personal Assistant

A simple command-line AI assistant built with Python.

## Features
- Responds to user greetings
- Plays mood-based music
- Stores and displays upcoming events
- Allows users to add events
- Allows users to delete events
- Uses typing effects for a better user experience

## Technologies Used
- Python
- Lists
- Dictionaries
- Functions
- Loops
- File handling
- Error handling

## How To Run

1. Make sure Python is installed
2. Open the project folder
3. Run the program using:

```bash
python main.py
```

## Example Commands
- Hello
- I Want To Listen To Music
- Help Me Check If I Have Any Upcoming Events
- I Want To Add An Event
- Delete An Event
- Bye

## Project Goal
This project was created as a beginner Python assistant project to practice programming fundamentals and user interaction.
