# 🧠 Internship Projects — Kc

A collection of three Python-based projects completed as part of an 
internship programme, each exploring a different area of software 
development and artificial intelligence.

---

## 📁 Projects Overview

### 1. 🤖 Rule-Based Chatbot
A conversational chatbot that responds to user input using a set of
predefined rules and pattern matching. Demonstrates the fundamentals
of natural language interaction without machine learning.

**Key Concepts:**
- Rule-based logic and decision trees
- String matching and pattern recognition
- Conversational flow design

---

### 2. 📊 Classification System
A machine learning classification system that uses the **K-Nearest 
Neighbors (KNN)** algorithm to categorise and predict outcomes based 
on input data.

**Key Concepts:**
- Supervised machine learning
- KNN algorithm implementation
- Data preprocessing and model evaluation

---

### 3. 🎓 Kc's Learning Platform
A command-line course recommendation system that collects user interests
and suggests the most relevant courses using a tag-based similarity
algorithm.

**Key Concepts:**
- Object oriented programming
- Tag-based recommendation logic
- User input handling and validation
