## Project 2 — Data Classification Using AI

A machine learning classification project built using the Iris dataset and the K-Nearest Neighbors (KNN) algorithm.

### Features

* Loads and preprocesses the Iris dataset
* Separates features and target labels
* Encodes categorical labels
* Splits data into training and testing sets
* Applies feature scaling using StandardScaler
* Trains a KNN classification model
* Evaluates model performance using:

  * Accuracy Score
  * Confusion Matrix
  * F1 Score
  * Classification Report

### Technologies Used

* Python
* Pandas
* Scikit-learn
* Machine Learning

### Machine Learning Concepts Used

* Supervised Learning
* Classification
* Feature Scaling
* Train-Test Splitting
* K-Nearest Neighbors (KNN)
* Model Evaluation

### Project Goal

This project was created to understand the fundamentals of supervised machine learning and how classification models are trained and evaluated.
