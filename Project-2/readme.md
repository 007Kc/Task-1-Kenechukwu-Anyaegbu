# Project 2 — Data Classification Using AI

## Overview

This project focuses on supervised machine learning using the Iris flower dataset.

The objective was to train a machine learning model capable of classifying flower species based on measurements such as petal length, petal width, sepal length, and sepal width.

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Machine Learning Concepts Used

* Supervised Learning
* Data Preprocessing
* Feature Scaling
* Train-Test Splitting
* K-Nearest Neighbors (KNN)
* Model Evaluation

## Workflow

1. Load the dataset
2. Separate features and labels
3. Encode target labels
4. Split dataset into training and testing sets
5. Scale feature values using StandardScaler
6. Train the KNN model
7. Predict test data
8. Evaluate model performance
